Como instalar (Android 8 ou superior)
  1. Toque no botão de download acima.
  2. Abra o arquivo baixado.
  3. Se pedir, permita “Instalar apps desconhecidos” para o navegador.
  4. Se o Play Protect avisar: Mais detalhes → Instalar mesmo assim.

Pode instalar por cima da versão antiga: a assinatura é a mesma e seus dados são mantidos. Os dois apps podem coexistir na mesma tela inicial.
